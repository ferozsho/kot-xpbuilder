{# Custom tail JS for Kot XPBuilder Superset stacks. Superset 6.1 native filters STAGE a "Clear all" (the select inputs empty) but only commit the clear when "Apply" is clicked — so charts kept their old values and the "Clear all" button looked broken. Auto-clicking Apply is unreliable (Apply can go stale/disabled), so this hook reaches the app's Redux store directly (via the React fiber tree) and dispatches UPDATE_DATA_MASK (value null) for every native filter: this clears the APPLIED data mask, re-queries all charts and collapses the filter chips in one go. #} {# Brand logo link fixer: clicking the navbar brand logo returns to the linked Moodle site instead of the Superset home page. * A per-launch `?xp_return=` wins — the Moodle connector's sso.php appends it when it opens the console, so leaving Superset lands back on the exact Moodle page that launched it (the dashboard the user was viewing). * XPBUILDER_BRAND_URL is the configured fallback (point it at the Moodle dashboard list) for arrivals that carry no launcher context. `xp_return` is honoured only when it points at XPBUILDER_MOODLE_URL, so the logo cannot be turned into an open redirect. The logo is a React-rendered anchor, so re-apply on an interval in case the app re-renders the navbar. #}
