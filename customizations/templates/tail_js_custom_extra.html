{# Custom tail JS for Kot XPBuilder Superset stacks. Superset 6.1 native filters STAGE a "Clear all" (the select inputs empty) but only commit the clear when "Apply" is clicked — so charts kept their old values and the "Clear all" button looked broken. Auto-clicking Apply is unreliable (Apply can go stale/disabled), so this hook reaches the app's Redux store directly (via the React fiber tree) and dispatches UPDATE_DATA_MASK (value null) for every native filter: this clears the APPLIED data mask, re-queries all charts and collapses the filter chips in one go. #} {# Brand logo link fixer: when XPBUILDER_BRAND_URL is configured, clicking the navbar brand logo goes to that URL instead of the Superset home page. The logo is a React-rendered anchor, so re-apply on an interval in case the app re-renders the navbar. #}
